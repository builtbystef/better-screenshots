# Security policy

Better Screenshots is a static, client-only web app. It has no backend, no
accounts, and no telemetry; images and settings never leave the browser
(uploads live in IndexedDB, settings in localStorage, both on the user's own
machine).

## Reporting a vulnerability

If you find a security issue — for example in how the app handles a crafted
image file, or in a dependency — please report it privately via
[GitHub security advisories](https://github.com/builtbystef/better-screenshots/security/advisories/new)
rather than a public issue. You should hear back within a week.
